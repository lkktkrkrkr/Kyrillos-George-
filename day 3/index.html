JS Day 3 Practice Tasks

String Manipulation & Interactive Menu Exercises

💡
Console Output Active

The tasks interact via prompt() prompts and output results to the browser console. Press F12 or Ctrl+Shift+I to open DevTools.

Task 01
Full Name Formatter
Capitalizes name words and counts characters excluding spaces.
Task 02
Email Validator
Checks @ symbol, .com ending, and spacing constraints.
Task 03
Character Counter
Counts occurrences of a specific character case-insensitively.
Task 04
Word Masker
Replaces target words in a sentence with asterisks (***).
Task 05
Username Generator
Combines names into lowercased dot format up to 15 chars.
Task 06
Word Position & Count
Finds first/last indices and total occurrences of a target word.
Task 07
Reverse Words
Reverses individual words while maintaining sentence order.
Task 08
Text Analyzer
Counts words, vowels, digits, cases, and finds longest/shortest words.
Task 09
Phone Number Masking
Masks middle digits of phone numbers with asterisks.
Task 10
Sentence Cleaner
Formats spaces, fixes JavaScript casing, capitalizes & adds period.
Bonus
Interactive Text Operations Menu
Provides an 8-option loop menu to perform string transformations dynamically.
